# 公众号 Markdown 排版工作台

一个纯前端静态网页工具，用来把 Markdown 文本快速排版成适合微信公众号粘贴的富文本样式。

## 文件

- `index.html`：页面入口
- `styles.css`：界面样式
- `app.js`：Markdown 解析、模板渲染、复制和导出逻辑

## 使用方式

直接双击打开 `index.html` 即可使用。

如果你想用本地服务方式打开，进入当前目录后执行：

```bash
python3 -m http.server 4173
```

然后访问：

```text
http://127.0.0.1:4173
```

## 操作流程

1. 把 Markdown 粘贴到左侧输入框。
2. 选择模板，并按需调整字号、行高、容器留白。
3. 检查右侧预览。
4. 点击“复制富文本”。
5. 回到微信公众号后台，直接粘贴。

## 已支持的 Markdown

- `#` 到 `###` 标题
- 普通段落
- `**粗体**`、`*斜体*`、`` `行内代码` ``
- 引用 `>`
- 无序列表 / 有序列表
- 分割线 `---`
- 代码块 ``````
- 表格
- 图片 `![alt](url)`

## 说明

- 页面输出的是内联样式 HTML，更适合复制到公众号后台。
- 不同公众号后台对样式的清洗程度不同，极少数情况下可能需要切换模板后再复制。
